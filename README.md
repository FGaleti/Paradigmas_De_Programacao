# Programming Paradigms

Academic repository created to store and organize activities, exercises, and implementations developed during the **Programming Paradigms** course, part of the **Software Engineering** degree program.

This project aims to document the progress of the studies conducted throughout the course, bringing together practical examples related to different programming models and software development approaches.

## Academic Information

- **Course Subject:** Programming Paradigms
- **Degree Program:** Software Engineering
- **Professor:** [Munif Gebara Junior](https://github.com/munifgebara)
- **Student:** [Felipe Galeti Gôngora](https://github.com/FGaleti)
- **Project Type:** Academic repository

## Objectives

This repository was created with the following objectives:

- Organize the activities developed throughout the course;
- Apply the concepts presented in class through practical exercises;
- Understand different ways of structuring and solving computational problems;
- Analyze the characteristics, advantages, and limitations of programming paradigms;
- Develop logical reasoning and abstraction skills;
- Explore different approaches to problem-solving;
- Maintain an academic record of the implementations completed during the course.

## Topics Covered

Throughout the course, this repository may include studies and implementations related to the following topics:

- Fundamental concepts of programming paradigms;
- Imperative programming;
- Procedural programming;
- Object-oriented programming;
- Functional programming;
- Logic programming;
- Code structuring and modularization;
- Abstraction and component reuse;
- Comparison between different programming models;
- Problem-solving using different approaches.

The content may be updated or expanded as the course progresses and new academic activities are completed.

## Repository Structure

The directory structure may vary according to the activities assigned throughout the academic term.

Each directory may contain:

- Activity source code;
- Practical exercises;
- Examples presented during classes;
- Individual or group assignments;
- Supplementary files;
- Specific documentation;
- Compilation and execution instructions.

When necessary, additional instructions will be provided within the corresponding activity directory.

## How to Use

To obtain a local copy of this repository, run the following command:

```bash
git clone https://github.com/FGaleti/Paradigmas_De_Programacao.git
```

Navigate to the project directory:

```bash
cd Paradigmas_De_Programacao
```

Then, browse the directories and files corresponding to each activity.

Requirements, dependencies, compilation commands, and execution procedures may vary depending on the programming language used in each exercise.

## Updating the Repository

To update the local copy with the latest changes from the main branch, run:

```bash
git pull origin main
```
